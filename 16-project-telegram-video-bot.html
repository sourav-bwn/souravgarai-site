01

The problem

Saving a video from a link usually means a cluttered website. I wanted the shortest path: paste the link into a chat and get the file back.

02

What I built

  • Telegram bot that takes any video link as a message
  • Downloads with yt-dlp and sends the file back in the chat
  • Drops the quality automatically when a file is over the 50 MB bot limit
  • Runs as a Docker webhook service on a free Render plan
03

The result

  • Live as @sourav_vidsave_bot on Telegram
  • Runs on a free Render plan with a webhook, no server to manage
  • Handles Telegram's 50 MB bot limit by lowering quality
  • Honest limits: slow first reply after idle, and some sites block server IPs
What it is

A Telegram bot, @sourav_vidsave_bot. You send it a video link and it downloads the video and sends it back as a file inside the chat. It runs as a webhook service on a free Render plan, so there is no server to look after.

The source repository is private. Limits are listed above because a free host and Telegram's file cap are real constraints.

// Challenges solved
Free hosting sleeps when idle, so the first message after a quiet spell can take about a minute to get an answer
Telegram caps files sent by bots at 50 MB, so the bot lowers the video quality to fit
Some sites, YouTube in particular, sometimes block server IP addresses, so those links can fail
