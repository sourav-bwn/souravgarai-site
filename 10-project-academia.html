ACADEMIA LMS

A full learning platform: student dashboard, admin panel, AI tests, homework, live classes, XP ranks and certificates.

Open live demo ↗
Live landing page of the Academia LMS (contact number blurred)
01

The problem

A coaching setup needs students to practise, show up and be tracked, and needs admins to run the whole thing. I set out to put all of it in one app instead of separate tools: tests, homework, live classes, attendance, ranks and an admin panel.

02

What I built

  • Subject-wise tests with difficulty options and an adaptive mode based on the previous score
  • Answer review, XP and levels
  • Role-based login for students and admins, Google sign-in, email-code sign-up and password reset
  • New students fill their details and wait for admin approval
03

The result

  • Live and public at rio-one-green.vercel.app
  • 360 AI test questions and 18 admin sections
  • Dashboard updates after a test without a page reload
  • Attendance and streak rules checked on the live app, including the mobile layout
What it is

A complete learning management system built from his own design screens. Students get a dashboard with real stats, homework, live-class reminders, a 360-question AI test bank, study hints, daily attendance and a streak. Admins manage students, courses, subjects, homework, materials, live classes, attendance, enquiries and feedback.

The source repository is private.
